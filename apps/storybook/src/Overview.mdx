# Components

FE Design Systems provides reusable UI components built on top of the design system tokens and Ant Design.

The components provide a consistent API while allowing common customization and interaction patterns.

## Available Components

### Button

A reusable action component supporting variants, appearances, sizes, and prefix or suffix content.

### Checkbox

A selectable input supporting primary and secondary variants.

### Input

A flexible form input supporting text, password, OTP, and textarea modes.

### Select

A dropdown input with support for custom sizing and disabled state.

### Switch

A toggle component supporting primary and secondary variants, as well as controlled and uncontrolled usage.

## Component Documentation

Each component page provides:

- Interactive examples
- Component states
- Available variants
- Custom API documentation
- Inherited properties from Ant Design

Explore the individual components from the sidebar to see their available APIs and usage examples.
