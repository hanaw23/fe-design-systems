# Foundations

Foundations define the visual language used throughout FE Design Systems.

They provide the shared values that components and applications can build upon.

## Available Foundations

### Colors

Defines the primitive and semantic colors used across the design system.

Use colors directly when working with low-level design values, or use semantic colors when building UI that should communicate meaning consistently.

### Typography

Defines the font families, font sizes, font weights, and line heights used by the design system.

### Spacing & Radius

Defines the spacing scale and border radius values used to maintain consistent layout and component shapes.

## Token Package

These foundations are provided through:

`@fe-design-systems/tokens`

The tokens package is framework-agnostic and can be consumed by different technologies.

For more details, explore the individual foundation pages in the sidebar.
